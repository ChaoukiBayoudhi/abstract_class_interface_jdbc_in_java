# Abstract class interface JDBC in Java

A Java application that talks to a database through JDBC.

## Tech stack

- Java
- Lombok

## Concepts covered

Stream API, abstract classes, collections, exception handling, inheritance, interfaces, lambda expressions.

## Project structure

- `Classes`: Car, DatabaseStorage, ListStorage, MotoCycle, Vehicle
- `database`: DBConnection
- `interfaces`: FuelConsumable, Persistable
- `src`: Main

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Main` (it contains the `main` method).

The code uses Lombok annotations: add the Lombok library and enable annotation processing in your IDE.

The JDBC code expects a running database server; set your own connection URL, username and password before running.
